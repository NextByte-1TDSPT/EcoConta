# EcoConta — NextBythe

Projeto desenvolvido para a **Global Solution 2026/2 da FIAP**, pela equipe **NextByte**.

O EcoConta é uma plataforma demonstrativa para acompanhamento do consumo residencial de água e energia, visualização de indicadores e organização de metas de consumo consciente.

## Acesse o projeto

[EcoConta — GitHub Pages](https://nextbyte-1tdspt.github.io/EcoConta/)

[EcoConta — Repositorio](https://github.com/NextByte-1TDSPT/EcoConta)

## Funcionalidades

- Página inicial com apresentação da plataforma.
- Acesso e gerenciamento de perfil.
- Painel com indicadores de consumo.
- Área de consumo de água e energia.
- Cadastro e acompanhamento de metas.
- EcoBot, com orientações sobre consumo consciente.
- Páginas Sobre, Integrantes, FAQ e Contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Lucide Icons e Font Awesome

## Como executar

1. Baixe ou clone o repositório https://github.com/NextByte-1TDSPT/EcoConta. 
2. Abra a pasta `EcoConta` e abra o arquivo `index.html`
3. A página inicial será aberta no navegador. Navegue pelas demais páginas pelo menu.

Também é possível abrir o `GitHub Pages` https://nextbyte-1tdspt.github.io/EcoConta/

## Observações

- Os dados salvos em `localStorage` ou `sessionStorage` ficam no navegador utilizado e não são sincronizados entre dispositivos.
- Valores e informações exibidos para demonstração não representam medições oficiais.
- Esta versão é um protótipo acadêmico/front-end, não um sistema de medição conectado a concessionárias.
